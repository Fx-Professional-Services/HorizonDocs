
# Discount

#### To create a discount:

1. In the main menu, click **Sales Orders**.
    
2. Go to **Item Management**, then select **Discount**. This will open the **Discounts** page.
    
3. Click **New Record** to create a new discount.
    
4. In the **Details** tab, enter the following information:
    
    - **Discount Name**: The name of the discount.
    - **Description**: A brief description of the discount.
    - **Discount Type**: Choose between **Percent** or **Fixed Amount**.
    - **Discount Value**: Enter the amount or percentage of the discount.
    - **Applies To**: Select whether the discount applies to items, the entire order, or selected items.
        - If you select **Selected Items**, a **Category** field will appear. Click the field to add an item category for the discount.
