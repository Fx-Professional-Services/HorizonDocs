# Return Order

A **Return Order** is the process of processing items returned by a customer, which updates the inventory and creates a record of the return. Follow these steps to create a return order:

### 1. Navigate to Sales Orders

- From the main menu, click **Sales Orders**.

### 2. Access Order Management

- Click **Order Management**, then select **Return Order**.

1. From the main menu, select **Sales Order**.
2. From the primary navigation, click **Order Management**, then select **Return Order**.
3. Click **New Record** from the secondary navigation.
4. Enter the **Party Display Name**.
5. Enter the **Return Date**.
6. Add line items.
7. Click the **Return Reason** field, then select a reason for each line item: **Cancelled Item**, **Wrong Item**, or **Damaged Item**.
8. Enter the **Return Quantity**.
9. Click **Confirm** once all line items are added. To verify that the inventory is updated, go to **Item Management** from the primary navigation, then click **All Items**. Search for each item added to the return order and verify that the return quantity appears in the **Returned** field for each item.
10. Click **Unconfirm** on the return order. To verify that the inventory is updated, go to **Item Management** from the primary navigation, then click **All Items**. Search for each item added to the return order and verify that the return quantity is deducted from the **Returned** field.
